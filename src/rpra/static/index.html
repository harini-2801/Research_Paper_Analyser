    Connect an analysis backend

    This page is the interface only. Browsing a saved analysis works without anything else, but uploading papers and running the pipeline need the Python API running somewhere.

    1. Run it locally — clone the repository and run pip install -e . && rpra serve. It opens on http://localhost:8000 and serves this interface itself, so nothing needs connecting.
    2. Or deploy it — the repository has a render.yaml. Create a Render web service from the repo and it will build and start the API.
    3. Then paste the URL below. The page reloads pointed at that API.
    An OpenAI key is optional. The default extraction backend is heuristic: it runs offline with no key and no account. A key only switches on LLM extraction and explanation generation, and it is set on the server as the OPENAI_API_KEY environment variable — never entered into this page.
